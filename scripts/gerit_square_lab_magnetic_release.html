Drag a square to move it. Drag its circular handle to rotate it freely. Geometry is continuous; the grid is only a guide.

Save / Load

Layouts are saved automatically in this browser when local storage is available. Use Start with + New board to reset to exactly N squares (1, 4, 25, 26, etc.). Add 4 / Add 25 instead adds that many to the current board. Each square always has side length exactly 1.

Controls

Click empty space to add a square. Select then use arrow keys to nudge by 0.05 units, Shift + arrow by 0.005 units; [ and ] rotate 1 degree. Mouse wheel zooms; drag empty space with the right mouse button to pan. Squares are rigid: motion and rotation stop at contact (edge contact is allowed). Magnetic contact is on by default; it attracts nearby corners and edges into contact when you release the mouse. Use Load exact 5-square packing to compare with the mathematical target 2.707106781.
